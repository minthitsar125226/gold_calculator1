# ⚒️ မြန်မာ့ရွှေပန်းတိမ်သုံး (Myanmar Gold Calculator)

မြန်မာ့ရွှေပန်းတိမ်လုပ်ငန်းအတွက် လိုအပ်သော ရွှေတွက်ချက်မှုများကို အလွယ်တကူနှင့် တိကျစွာ လုပ်ဆောင်နိုင်သော Python/Streamlit အခြေခံ App ဖြစ်သည်။

## ✨ အဓိက လုပ်ဆောင်ချက်များ (Features)

ဤ App တွင် အောက်ပါလုပ်ဆောင်ချက်များ ပါဝင်သည်။

* **ရွှေ နှင့် ငွေ လဲလှယ်ခြင်း**:
    * ရွှေအလေးချိန် (ကျပ်၊ ပဲ၊ ရွေး၊ Point) ထည့်သွင်း၍ ကျသင့်ငွေကို ချက်ချင်းတွက်ချက်နိုင်သည်။
    * မိမိတွင်ရှိသော ငွေပမာဏဖြင့် ဝယ်ယူနိုင်သည့် ရွှေအလေးချိန်ကို ပြန်လည်တွက်ချက်နိုင်သည်။
* **ပန်းတိမ်သုံး အချိုးအစားတွက်စက်**: 
    * လက်ဝတ်ရတနာဒီဇိုင်းများအတွက် အချိုးကျ အရှည်နှင့် အလေးချိန်များကို အမြန်တွက်ချက်နိုင်သည်။
* **ကမ္ဘာ့ရွှေဈေးမှ မြန်မာ့ရွှေဈေးတွက်ချက်ခြင်း**:
    * World Spot Gold ဈေးနှုန်းကို ဒေါ်လာဈေးနှင့် မြှောက်၍ မြန်မာ့အခေါက်ရွှေဈေးကို ခန့်မှန်းတွက်ချက်နိုင်သည်။
* **လက်စွပ်/လက်ကောက် တိုင်းတာခြင်း**:
    * လက်ဝတ်ရတနာများအတွက် သင့်လျော်သော ဆိုဒ်များကို ပဲစနစ်ဖြင့် တွက်ချက်ပေးနိုင်သည်။

## 🛠 နည်းပညာများ (Technology Stack)

* **Language**: Python
* **Framework**: Streamlit
* **Libraries**: Streamlit (for UI), Math (for calculations)
